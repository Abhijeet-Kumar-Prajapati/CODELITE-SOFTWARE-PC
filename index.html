Questions

Straight answers

Does it need an internet connection?

No. After install it makes zero network calls — no telemetry, no analytics, no update ping. You can unplug the cable and it behaves identically.

Why does it start a small local server?

Only so the browser treats it as a secure origin. Browsers block folder and file access on file:// pages, so CodeLite serves itself from localhost and opens there. It is not reachable from your network.

How do I install it?

Download the installer, double click it, choose your shortcuts, done. It is a per-user install and never asks for administrator rights.

Which browsers does it use?

Edge and Chrome. Folder access relies on the File System Access API, which those two implement fully, so CodeLite opens in a dedicated app window rather than a normal tab.

Will Windows warn me about the download?

Yes, the installer is not code-signed yet, so SmartScreen may show a warning the first time. Click More info → Run anyway.

Can I open a project outside my Documents folder?

Yes. You pick the folder and the browser asks you to confirm once. Nothing is uploaded anywhere — the files stay on your disk.
