Questions

Does it need an internet connection?

No. Once installed it makes zero network calls. No telemetry, no analytics, no update pings. The bundled local server binds to 127.0.0.1 only and validates every request path against the install directory.

Why does it need a small local server?

Only so the browser treats it as a secure origin. Browsers block folder and file access on file:// pages, so CodeLite serves itself from localhost and opens there. It is not reachable from your network.

How do I install it?

Download the installer above and double click it. It is a per-user install, so it never asks for administrator privileges. You choose whether to create Desktop and Start Menu shortcuts, then launch CodeLite like any other program.

Which browsers does it use?

Edge and Chrome. Folder access uses the File System Access API, which those two implement fully, so CodeLite opens in a dedicated app window rather than an ordinary browser tab.
